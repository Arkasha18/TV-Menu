# Поддержка

- Ошибки приложения оформляйте через
  [Issues](https://github.com/Arkasha18/TV-Menu/issues).
- Вопросы по сборке, идеи и обсуждения публикуйте в
  [Discussions](https://github.com/Arkasha18/TV-Menu/discussions).
- Уязвимости открывайте только через
  [Private vulnerability reporting](https://github.com/Arkasha18/TV-Menu/security/advisories/new).
- По вопросам коммерческого использования: [arkasha18@gmail.com](mailto:arkasha18@gmail.com).

Проект не предоставляет консультаций по обходу защитных механизмов телевизора
и не гарантирует работу на всех прошивках Android TV / Google TV.
