# Участие в разработке

Спасибо за интерес к TV Меню. Проект принимает исправления, улучшения
интерфейса, документации и новые идеи.

## Перед началом

1. Создайте Issue или обсудите заметное изменение в Discussions.
2. Не публикуйте пароли, ключи подписи, токены и необработанные диагностические материалы.
3. Учитывайте, что служба специальных возможностей и локальный ADB — чувствительные механизмы; изменения в них требуют осторожности.

## Сборка

Рекомендуемый воспроизводимый способ:

```bash
docker build --platform linux/amd64 -t tv-menu-build .
docker run --rm --platform linux/amd64 \
  -v "$PWD:/workspace" -w /workspace \
  tv-menu-build
```

Локальная сборка требует JDK 17 и Android SDK 35:

```bash
./TvQuickMenu/gradlew -p TvQuickMenu assembleDebug lintDebug
```

На Windows можно использовать `build.bat` или `scripts\docker-build.bat`.

## Pull Request

- создавайте отдельную ветку для каждого изменения;
- объясняйте назначение и способ проверки;
- прикладывайте снимки для визуальных изменений;
- убедитесь, что GitHub Actions завершился успешно.

Отправляя вклад, вы подтверждаете право публиковать его и соглашаетесь на
распространение вклада по лицензии проекта
[PolyForm Noncommercial 1.0.0](LICENSE). Сторонние материалы должны иметь
отдельно указанную совместимую лицензию.
