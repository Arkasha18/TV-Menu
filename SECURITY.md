# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются для актуальной версии из раздела
[Releases](https://github.com/Arkasha18/TV-Menu/releases).

| Версия | Поддержка |
| --- | --- |
| 1.x | Да |
| Более ранние версии | Нет |

## Как сообщить об уязвимости

Используйте
[Private vulnerability reporting](https://github.com/Arkasha18/TV-Menu/security/advisories/new).
Не создавайте публичный Issue до согласованного раскрытия проблемы.

В отчёте укажите:

- затронутую версию и устройство;
- безопасные шаги воспроизведения;
- возможное влияние;
- предлагаемый способ исправления, если он известен.

Не прикладывайте пароли, ключи, токены, дампы памяти и другие чувствительные данные.
Если без файла нельзя подтвердить проблему, сначала опишите его состав без вложения.

## Границы проекта

TV Меню — утилита для Android TV / Google TV. Уязвимости, позволяющие
эскалировать права на устройстве, выполнять произвольный код или обходить
ограничения пользователя без согласия, считаются критическими.

Автор постарается подтвердить получение отчёта в течение семи дней, но
фиксированное время выпуска исправления не гарантируется.
