# TV Меню

Приложение для Android TV / Google TV: назначение кнопки пульта (в том числе «Иви»), меню с таймером сна и затемнением экрана.

## Возможности

- программирование специальной кнопки пульта;
- быстрое меню: таймер сна и 5 уровней затемнения;
- основный режим **без ПК** — через службу специальных возможностей;
- локальный ADB — только дополнительный вариант.

## Требования

- Android TV / Google TV, Android 9+;
- разрешение «поверх окон» для затемнения;
- служба «TV Меню» в специальных возможностях.

На части телевизоров (например Haier) система может сбрасывать любую службу специальных возможностей — это ограничение прошивки.

## Сборка

Нужны JDK 17 и Android SDK. Из каталога `TvQuickMenu`:

```bat
gradlew.bat assembleDebug
```

Или из корня (если рядом лежит локальный `tools\`):

```bat
build.bat
```

APK: `TvQuickMenu\app\build\outputs\apk\debug\app-debug.apk`

## Установка

1. Установите APK.
2. Разрешите показ поверх окон.
3. Включите службу кнопок «TV Меню».
4. Запрограммируйте кнопку пульта.

Скрипты `setup-adb.bat`, `install.bat`, `enable-accessibility.bat` — вспомогательные для разработки с ПК.
